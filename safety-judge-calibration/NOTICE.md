# Notice and label provenance

This package is an original calibration and reporting implementation. It does
not copy an upstream judge implementation, prompt set, model output or dataset.

The 200 frozen requests are generated audit cases from
`agent-safety-eval/dataset/judge-cases-v1.jsonl`. Their bundled labels are
assistant-authored drafts and must not be represented as human annotations.
The associated Agent Safety NOTICE records the public projects that informed
the broader design space.

> **本地安全评测，不是生产安全系统。 Local safety evaluation, not a production security system.**
