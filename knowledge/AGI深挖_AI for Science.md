## 引子：科学发现的第四范式

第一范式：实验科学（几千年前）——伽利略、牛顿"做实验、看现象"
第二范式：理论科学（几百年前）——爱因斯坦、麦克斯韦"推导方程"
第三范式：计算科学（几十年前）——冯·诺依曼"用计算机模拟"
**第四范式：AI驱动科学（2020年代）——用AI从数据中发现定律、预测结果、生成假设**

2026年，第四范式已经从一个"前沿概念"变成了"日常工具"。大约30%的《自然》《科学》论文使用了AI方法。

## 一、蛋白质结构预测——AlphaFold3及之后

### 1.1 AlphaFold3的核心创新（2024→2026）

```
AlphaFold2 (2021): 改变生物学的革命
  输入: 氨基酸序列
  输出: 蛋白质3D结构
  精度: 接近实验（~90%的预测与实验一致）
  局限: 只预测静态结构、只预测单体蛋白质

AlphaFold3 (2024): 从蛋白质到分子交互
  输入: 蛋白质 + DNA/RNA/小分子
  输出: 复合物的3D结构
  精度: 比AF2提升约20%（特别是对蛋白质-药物分子复合物）
  关键创新:
    Pairformer架构（替代Evoformer）
    扩散模型用于结构生成
    统一处理所有分子类型

AlphaFold3的后续影响（2024-2026）:

① 结构生物学的方法论变革:
  使用AI预测代替X射线晶体学（节省数月时间）
  X射线晶体学的使用量在美国下降约30%
  Cryo-EM与AI结合成为主流方法

② 药物发现中的应用:
  预测药物分子与靶点的结合方式
  大幅缩短"先导化合物优化"阶段
  部分取代高分辨率的X射线结构测定

③ 开源vs闭源:
  DeepMind最初不开源AF3 → 学术界不满
  → 2025年部分开源（非商业限制）
  → 中国团队（PaddleHelix、ZetaCom）在AF2基础上推出自己的改进版
```

### 1.2 AlphaFold之后的其他重要结构预测工具

```
ESMFold (Meta, 2023-2025):
  使用语言模型方法
  用蛋白质序列做"下一token预测"
  "理解"蛋白质序列的"语法"
  速度: 比AF2快数十倍（秒级vs小时级）
  优点: 特别擅长预测未知折叠（novel fold）
  缺点: 整体精度略低于AF3

RoseTTAFold Diffusion (2023-2025):
  David Baker实验室的蛋白质设计工具
  用扩散模型直接从蛋白质骨架生成结构
  核心应用: 设计全新的蛋白质（de novo protein design）
  2026: 已经成功设计了数百种自然界不存在的蛋白质
  ﹣部分已被用于药物开发和生物材料

Boltzmann Generator (2023-2026):
  生成蛋白质构象系综（不只是预测一个结构）
  理解蛋白质的"动态"——很多蛋白质的功能依赖于结构变化
  支持"构象采样"——预测蛋白质可能采取的多种形状
```

### 1.3 蛋白质设计的工程化——"生物学的编译器"

```
2026年最令人兴奋的方向——蛋白质设计自动化:

人类: "设计一个能催化特定反应的酶"
AI流程:
  ① 确定催化机制（理论模拟 + AI推理）
  ② 生成候选蛋白质骨架（RF diffusion）
  ③ 设计氨基酸序列（ProteinMPNN）
  ④ 预测结构验证（AlphaFold3）
  ⑤ 计算结合能（Rosetta + AI）
  ⑥ 筛选最佳候选
  ⑦ 合成基因 → 表达 → 实验验证

这实质上是一个"蛋白质编译器":
  输入: 功能需求
  输出: 蛋白质序列
  编译过程: AI取代化学直觉

2026年状态:
  "蛋白质设计"的成功率约10-30%
  仍然低于天然酶设计的成功率
  但对于天然不存在的"新酶"设计来说，已是巨大进步
```

## 二、AI数学证明

### 2.1 里程碑回顾

```
2022年: 首次AI辅助数学发现
  DeepMind发现"新的数学猜想"（结理论）
  但: AI只是提出猜想，人类完成证明

2024年: AlphaProof
  在IMO（国际数学奥林匹克）上获得银牌级别
  使用强化学习 + 形式化验证（Lean）
  证明方法不同于人类——"计算暴力"风格

2025年: 首次AI完成的原创数学证明
  AI首次独立完成了一个有发表价值的定理证明
  题目: 关于数论的一个中等难度定理
  证明方法: 人类无法理解（但被验证正确）
  争议: 这是否算真正的"数学发现"？

2026年: 定理证明的工程化
  AlphaProof + Gemini Robotics + Codex的组合
  全自动的定理证明管线
  在组合数学和数论领域取得了20+个原创结果
```

### 2.2 AI数学证明的技术方案

```
方案A: 形式化验证 (Formal Verification)
  使用Lean、Coq、Isabelle等交互式定理证明器
  AI生成证明→形式化验证系统检查
  优势: 100%正确（如果验证通过）
  劣势: 速度慢、需要大量"证明工程"

方案B: 神经推理 (Neural Reasoning)
  使用LLM直接生成数学推理
  不需要形式化验证
  优势: 速度快、可以"猜测"
  劣势: 可能出错、越长的推理链越不可靠

方案C: 神经符号混合 (2025-2026, SOTA)

  AlphaProof的架构:
    ① 神经猜想: LLM生成"可能的证明方向"
    ② 符号搜索: 使用搜索算法探索证明路径
    ③ 形式化验证: Lean验证每个步骤
    ④ 强化学习: 从成功/失败的证明中学习
    
  关键: 神经猜想的质量决定了搜索效率
  2026年: 猜想准确率已达到约60%（即60%的猜想方向能导向有效证明）
```

### 2.3 AI数学发现的局限性

```
1. "理解"还是"模式匹配"？
  人类数学家: 理解定理的"意义"和"本质"
  AI: 可能在做模式匹配（"这个结构和那个证明模式相似"）
  一个定理被证明后，AI不知道"为什么这个定理重要"

2. 价值判断:
   人类可以判断一个定理是否"有趣"
   AI目前无法区分"深刻"和"琐碎"的数学结果
   很多AI生成的证明是"技术上正确但毫无价值"的

3. 领域偏向:
   组合数学和数论: AI进步最快
   几何和拓扑: AI进步较慢（需要空间直觉）
   (2026年的状况: 差距在缩小但仍然存在)

4. 可解释性:
   AI生成的证明往往"不优雅"
   人类难以理解证明的思路
   类似于"暴力穷举"的自动定理证明器
   但2026年的AI已经比纯暴力搜索聪明得多
```

## 三、学习型模拟器——AI物理仿真

### 3.1 传统模拟 vs 学习型模拟

```
传统物理模拟:
  基于方程（流体力学N-S方程、分子动力学牛顿方程）
  离散化 → 数值求解
  精度高、但计算量大、速度快不起来

学习型模拟（Learned Simulator）:
  使用神经网络直接模拟物理过程
  不需要显式求解方程
  速度: 比传统模拟快100-1000倍
  精度: 在某些场景下接近传统模拟
  适用: 需要"近似模拟但够用"的场景
```

### 3.2 2026年主要的学习型模拟器

```
① 蛋白质分子动力学模拟:
  传统MD: 模拟1微秒需数周
  AI加速MD: 模拟1微秒需数小时
  AI方案: 学习"下个状态"的预测模型
  精度: 关键指标（RMSD）与MD相差<10%
  实际应用: 药物结合动力学、蛋白质折叠路径

② 材料科学:
  模拟新材料的机械、热力学、电子性质
  AI预测晶格结构、能带、弹性模量
  从"筛选100种材料" → "让AI筛选1000万种"
  2026年: AI已经发现了多种新型电池材料

③ 气候模拟:
  AI加速气候模型（预报速度提升100倍）
  Google DeepMind的GraphCast: 10天天气预报在60秒内完成
  精度: 在多数气象指标上优于传统数值预报
  局限: 极端天气预测的可靠性较低

④ 流体模拟:
  AI Navier-Stokes求解器
  NVIDIA的Physics-ML模型
  汽车风洞模拟、飞机气动设计
  速度: 传统CFD可能需要数天，AI只需数分钟
```

### 3.3 神经算子（Neural Operator）——学习型模拟的核心技术

```
物理模拟本质上是在求解偏微分方程（PDE）。

2024-2026年最重要的突破: 傅里叶神经算子（FNO）等架构

傅里叶神经算子 (FNO):
  输入: 初始条件 + 边界条件 + PDE系数
  输出: 未来时刻的解
  操作: 在傅里叶空间中学习算子（不是直接预测解，而是学习PDE的解算子）

DeepONet (2025改进版):
  分离学习: 编码器+解码器架构
  将物理系统的"系统特性"和"边界条件"分离学习

Operator Learning的通用方案:
  ① 在多个物理系统上预训练"基础算子模型"
  ② 在特定PDE上微调
  ③ 实现"一次训练，所有PDE通用"
  
2026年状态:
  基础算子模型在~80%的常见PDE上表现良好
  但对于复杂湍流和多尺度物理，仍然需要专用模型
```

### 4.3 分子生成——AI设计新分子

```
分子生成的三种AI范式:

① 基于语言模型:
  将分子表示为SMILES或SELFIES字符串
  用LLM直接生成"看起来合理"的分子
  代表: MolGPT、ChemBERTa
  优势: 快速、简单
  劣势: 生成的分子可能无法合成

② 基于图神经网络:
  将分子表示为图（原子=节点、化学键=边）
  在图上进行生成和优化
  代表: GraphAF、MoFlow
  优势: 更自然的分子表示
  劣势: 计算更复杂

③ 基于扩散模型（2026年SOTA）:
  从噪声开始逐步恢复分子结构
  可以条件生成（结合目标蛋白质）
  代表: DiffDock、EquiDiff
  优势: 生成质量最高、可以优化多目标
  劣势: 速度慢

2026年实际管线:

  "设计一个对EGFR有抑制活性、同时血脑屏障穿透率低、 
  且合成步骤不超过5步的分子"

  AI方案:
    ① 蛋白质-药物对接得分预测（AlphaFold3+Physicochemical）
    ② 药物相似性过滤（Lipinski规则+AI吸收预测）
    ③ 合成可行性评估（AI retrosynthesis分析）
    ④ 毒性预测（AI toxicity模型）
    ⑤ 多目标优化（Pareto前沿）
    
  结果: 从~10^60的化学空间中找到~100个候选
  人类化学家从中挑选10个合成测试
  2026年: 命中率~30-50%（10个中3-5个有活性）
  对比2023年: 命中率~10-20%
```

## 五、AI实验自动化——"AI科学家"

### 5.1 闭环实验系统

```
2026年最激动人心的趋势——AI自主实验：

示意图:

  生成假设 → 设计实验 → 执行实验 → 
  分析结果 → 更新假设 → 再设计实验 → ...

完全闭环（人类只监督）:

  ① 假设生成（LLM）
    "基于已有文献，我假设X蛋白在Y条件下与Z药物有更强的结合"

  ② 实验设计（AI规划）
    设计方案: "使用表面等离子共振技术(SPR)，在pH=7.4、25°C下检测"

  ③ 实验执行（机器人）
    机器人自动执行SPR实验
    液体处理、样品转移、数据采集

  ④ 结果分析（AI数据分析）
    分析结合曲线
    计算KD值
    评估假设

  ⑤ 假设更新（LLM）
    根据实验结果改进假设
    "X蛋白结合强，但Z药物的选择性不如预期，建议更换为Z'类似物"
```

### 5.2 "自主实验室"的现状

```
2026年的自主实验室（AutoLab）：

已经实现的:
  AI驱动的自动化药物筛选管线
  自动化的材料合成和表征
  自动化的微生物培养和检测

尚未实现的:
  完全自主的"假设提出→验证→新假设提出"循环
  灵活应对实验中的意外情况
  修理故障设备

代表系统:
  DeepMind的BioAgent:
    LLM + 视觉模型 + 机械臂
    可执行生物实验室中的标准操作
    2026年状态: 在标准化的测试套件中~80%的任务成功

  MIT的CryoGrid:
    自动化材料合成 + 表征
    每天运行100+个实验
    自主优化材料配方

  智源研究院的AutoLab:
    面向生化实验的AI科学家
    2019年启动 → 2026年达到中等技术员的水平
```

### 5.3 "AI科学家" vs 人类科学家

```
AI的优势:
  ① 24/7连续工作（不累、不睡觉、不放假）
  ② 读取速度: 每分钟读数千篇论文摘要
  ③ 记忆: 过目不忘、精确检索
  ④ 一致性: 每次做实验都一样（不疲劳、不受情绪影响）
  ⑤ 并行性: 可以同时运行许多实验

人类科学家的优势:
  ① 直觉: "我觉得这个方向更有希望"
  ② 创造力: "为什么不试试这个完全不同的方法？"
  ③ 跨学科连接: "这个物理中的概念可能适用于生物学"
  ④ 应对意外: "实验结果和预期不一样，这本身就是一个发现"
  ⑤ 社会协作: "我的同事最近发现了一个有趣的现象"

2026年状态:
  AI科学家在"高通量筛选"和"数据驱动发现"上超越了人类
  人类科学家在"假设性发现"和"范式转换"上仍不可替代
  最佳组合: AI处理数据密集的工作 + 人类提出创造性方向
```

## 六、展望：AI for Science 的 2027-2030

1. **第一个"AI发现并验证"的基础定理**：预测在2-3年内，AI会发现一个在数学或物理学上具有重大意义的新定理或定律

2. **"AI合成科学家"的雏形**：在下一个5年内出现能自主管理实验室并做出发现的系统，但还不会独立选择"值得研究的问题"

3. **"AI增强"成为所有科学领域的基础设施**：就像今天所有的科学家都使用计算机一样，10年后所有科学家都将使用AI工具

4. **科学方法论本身的变革**：
   - 科学假设不再需要"人类可理解"——只要预测准确且可验证
   - 科学论文中将出现大量"AI生成的实验"
   - "可复现性危机"可能被AI缓解（AI严格遵循实验协议）

5. **最大的科学突破可能来自AI**：
   - 新材料（室温超导体？）
   - 新药物（通用抗病毒？）
   - 新物理（修正标准模型？）
   - 新数学（黎曼猜想的证明？）
   
   这些都可能来自AI。2026年，我们不知道这些突破什么时候会发生。但在2026-2030年之间，这不再是不可能的。
