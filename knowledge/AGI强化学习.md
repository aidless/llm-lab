# AGI 强化学习

---

## 总览：从试错中涌现的智能

强化学习（Reinforcement Learning, RL）——是"从交互中学习"的数学框架——也是 AGI 路径上——与"预训练+缩放"互补的另一条主线。语言模型只会"预测下一个 token"——而 RL 教它"为了长期回报做决策"。AlphaGo、AlphaFold、OpenAI o1/R1 系列——背后都有 RL 的核心引擎。RL 的价值——不在于取代监督学习——而在于它提供了"目标函数缺失时如何学习"的答案：智能体与环境的闭环交互——试错——奖励——改进。

```
        ┌──────────────────────────────────────────────┐
        │                    环境                        │
        │                                               │
   sₜ ──┤ 状态转移 P(sₜ₊₁|sₜ,aₜ)                         │
        │                                               │
        └──┬────────────────────────────▲───────────────┘
           │                            │
           ▼                            │ rₜ 奖励
   ┌───────────────┐      aₜ            │
   │   智能体       │ ──────────────────┘
   │ 策略 π(a|s)    │
   │ 价值 V(s)      │
   │ 回报 Gₜ        │
   └───────────────┘
        ▲
        │ 学习信号: TD误差 / 策略梯度 / 熵
        ▼
   RL 算法族 ──→ 表格方法 ──→ 深度 RL ──→ 多智能体 ──→ RLHF/GRPO 与 LLM
```

RL 的核心难题——"信用分配"（哪个动作导致了最终回报）与"探索-利用权衡"——贯穿本文全部章节。理解 RL——等于理解 LLM 后训练（post-training）的全部秘密。

## 一、MDP 与贝尔曼方程

### 1.1 MDP 的形式化定义

**马尔可夫决策过程**（Markov Decision Process, MDP）——由五元组定义：

```
MDP = (S, A, P, R, γ)
```

- **S**：状态集合（state space）——智能体可观测的环境状态
- **A**：动作集合（action space）
- **P(s'|s, a)**：状态转移概率——给定状态 s 与动作 a——下一状态 s' 的分布
- **R(s, a, s')**：奖励函数——即时反馈信号
- **γ ∈ [0, 1)**：折扣因子——未来回报的衰减系数

**马尔可夫性**——MDP 的"核心假设"：未来状态只依赖当前状态与动作——与更早的历史无关：

```
P(sₜ₊₁ | sₜ, aₜ, sₜ₋₁, aₜ₋₁, ...) = P(sₜ₊₁ | sₜ, aₜ)
```

### 1.2 回报与折扣因子

**回报**（Return）——从时刻 t 开始的累计折扣奖励：

**核心公式**：
```
Gₜ = rₜ₊₁ + γrₜ₊₂ + γ²rₜ₊₃ + ... = Σₖ₌₀^∞ γᵏ rₜ₊ₖ₊₁
```

- γ 越小——智能体越"短视"——只关心近期奖励
- γ 越大——智能体越"远视"——但方差与不确定性也越大
- γ < 1 保证无穷级数收敛——（当奖励有界时）
- 折扣因子还隐含"时间偏好"——与金融贴现、因果推断中的衰减一致

### 1.3 价值函数

**状态价值函数**（State-Value Function）——从状态 s 出发、按策略 π 行动的期望回报：

```
V_π(s) = E_π[Gₜ | sₜ = s]
```

**动作价值函数**（Action-Value Function）——从状态 s 采取动作 a 后按策略 π 行动的期望回报：

```
Q_π(s, a) = E_π[Gₜ | sₜ = s, aₜ = a]
```

两者的关系：

```
V_π(s) = Σ_a π(a|s) · Q_π(s, a)
```

**最优价值函数**——所有策略中期望回报最大者：

```
V*(s) = max_π V_π(s)
Q*(s, a) = max_π Q_π(s, a)
```

**最优策略**——满足：只要最优动作价值 Q* 已知——最优策略就是贪心：

```
π*(a|s) = argmax_a Q*(s, a)
```

### 1.4 贝尔曼方程（Bellman Equations）

贝尔曼方程——把"当前价值"分解为"即时奖励 + 未来价值"——是 RL 一切算法的"根"。

**贝尔曼期望方程**（Bellman Expectation Equation）：

```
V_π(s) = Σ_a π(a|s) Σ_s' P(s'|s,a) [ R(s,a,s') + γV_π(s') ]
Q_π(s,a) = Σ_s' P(s'|s,a) [ R(s,a,s') + γ Σ_a' π(a'|s') Q_π(s',a') ]
```

**贝尔曼最优方程**（Bellman Optimality Equation）——用 max 替代期望：

```
V*(s) = max_a Σ_s' P(s'|s,a) [ R(s,a,s') + γV*(s') ]
Q*(s,a) = Σ_s' P(s'|s,a) [ R(s,a,s') + γ max_a' Q*(s',a') ]
```

### 1.5 收敛性：压缩映射与不动点

为什么贝尔曼方程可以迭代求解？——因为"贝尔曼算子"是一个**压缩映射**（contraction mapping）：

```
|TV₁(s) - TV₂(s)| ≤ γ · max_s |V₁(s) - V₂(s)|     (γ < 1)
```

- 贝尔曼算子 T 每次迭代——把价值函数之间的距离至少压缩 γ 倍
- 由巴拿赫不动点定理——重复应用 T 必然收敛到唯一不动点——即最优价值函数
- 收敛速率——O(γᵏ) 几何级数——这是"价值迭代"可行性的理论保证
- 在连续状态/动作空间——压缩映射论证依然成立——但需要函数逼近——出现新的误差源

## 二、动态规划：策略迭代与价值迭代

动态规划（Dynamic Programming, DP）——要求"模型已知"（P 与 R 完全给定）——是 RL 的"理想化实验室"——后续所有无模型方法都是它的推广。

### 2.1 策略评估（Policy Evaluation）

给定一个策略 π——迭代计算其价值函数：

```
V₀ = 0
Vₖ₊₁(s) = Σ_a π(a|s) Σ_s' P(s'|s,a) [ R(s,a,s') + γVₖ(s') ]
```

- 每次迭代——一次全状态扫描（sweep）
- 直到 ‖Vₖ₊₁ - Vₖ‖ < θ（阈值）——即收敛
- 实际中——迭代到"足够好"即可——不必完全收敛

### 2.2 策略改进与策略迭代

**策略改进定理**：若对每个状态 s：

```
Q_π(s, π'(s)) ≥ V_π(s)   （π' 在每点不劣于 π）
```

则 π' 的价值函数——处处不劣于 π：V_π'(s) ≥ V_π(s)。

**贪心改进**——选择动作：

```
π'(s) = argmax_a Q_π(s, a)
```

**策略迭代**（Policy Iteration）——交替执行：

```
循环:
  1. 策略评估: 用贝尔曼期望方程迭代算出 V_πₖ
  2. 策略改进: πₖ₊₁(s) = argmax_a Σ_s' P(s'|s,a)[R + γV_πₖ(s')]
  直到策略不再变化
```

- 每轮改进——价值单调上升
- 有限 MDP 下——策略数量有限——保证有限步收敛到最优策略
- 每轮策略评估通常不需要完全收敛——截断后就是"广义策略迭代"的原型

### 2.3 价值迭代（Value Iteration）

不显式维护策略——直接迭代最优贝尔曼方程：

```
Vₖ₊₁(s) = max_a Σ_s' P(s'|s,a) [ R(s,a,s') + γVₖ(s') ]
```

收敛后：

```
π*(s) = argmax_a Σ_s' P(s'|s,a) [ R(s,a,s') + γV*(s') ]
```

- 价值迭代 = 截断到 1 次的策略迭代——每次改进都"隐含地"改策略
- 策略迭代收敛更快（每轮更贵）；价值迭代实现更简单（每轮更便宜）
- 在问题规模较大时——价值迭代的迭代次数随 γ/(1-γ) 增长——"近终局惩罚"问题

### 2.4 广义策略迭代（GPI）

**核心思想**：策略评估与策略改进——不必严格交替——可以交错进行——只要两者都不断向目标推进。

```
┌────────────────────────────┐
│   π ──(评估)──→ V_π         │
│   ↑                        │
│   (改进)                    │
│   │                        │
│   └──── V_π ──(贪心)───┘    │
└────────────────────────────┘
```

GPI 是理解所有 RL 算法的"统一镜头"：
- Q-Learning = 单步截断的 GPI + 无模型采样
- Actor-Critic = GPI 的"策略梯度"版本
- DQN = GPI + 神经网络 + 经验回放

### 2.5 动态规划的局限

- **需要完整模型**——真实环境通常没有 P 与 R
- **状态爆炸**——表格形式存不下高维状态（围棋 10^170 状态——只能用函数逼近）
- **同步扫描昂贵**——大规模问题需要异步/采样式更新
- 这些局限——直接催生了"无模型 RL"——只用与环境交互的数据学习

## 三、无模型 RL：时序差分与 Q-Learning

### 3.1 蒙特卡洛 vs 时序差分（TD）

**蒙特卡洛（MC）**——跑完整个 episode——用真实回报 Gₜ 更新：

```
V(sₜ) ← V(sₜ) + α [ Gₜ - V(sₜ) ]
```

- 无偏——但方差大——必须等 episode 结束——只能用于有终止的回合制任务

**时序差分（TD）**——只等一步——用"自举"（bootstrap）估计替代真实回报：

```
TD(0):  V(sₜ) ← V(sₜ) + α [ rₜ₊₁ + γV(sₜ₊₁) - V(sₜ) ]
```

- 有偏（依赖自身估计）——但方差小——可在线、增量式学习
- **TD 误差** δₜ = rₜ₊₁ + γV(sₜ₊₁) - V(sₜ)——是 RL 中最核心的信号
- TD(λ)——用资格迹（eligibility trace）在 MC 与 TD(0) 之间插值

### 3.2 Q-Learning 与 SARSA

**Q-Learning（离策略）**——从任意行为策略采样的数据——更新目标策略的最优 Q：

**核心公式**：
```
Q(sₜ, aₜ) ← Q(sₜ, aₜ) + α [ rₜ₊₁ + γ max_a' Q(sₜ₊₁, a') - Q(sₜ, aₜ) ]
```

- max 来自"目标策略"（贪心）——而行为策略可以是 ε-greedy——这就是"离策略"（off-policy）
- 收敛性由随机逼近理论保证（Robbins-Monro 条件：Σα = ∞, Σα² < ∞）

**SARSA（在策略）**——用"当前行为策略"的实际下一动作更新：

```
Q(sₜ, aₜ) ← Q(sₜ, aₜ) + α [ rₜ₊₁ + γQ(sₜ₊₁, aₜ₊₁) - Q(sₜ, aₜ) ]
```

- 学习的是"跟随自己的策略"的价值——对探索更保守——著名的"悬崖行走"例子中——SARSA 学会绕行——Q-Learning 学会贴崖边（但偶尔坠崖）

### 3.3 探索与利用（Exploration vs Exploitation）

- **ε-greedy**：以 ε 概率随机动作——简单但探索"无记忆"——可能重复访问
- **UCB（上置信界）**：按 Q(s,a) + c·√(ln t / N(s,a)) 选择——对"访问次数少"的动作自动加奖励——平衡探索与利用
- **Boltzmann 探索**：按 softmax(Q(s,a)/τ) 采样——温度 τ 控制随机性
- **Thompson 采样**：从 Q 的后验分布采样——贝叶斯风格
- 深度 RL 时代——噪声注入（NoisyNet）、熵正则（SAC/PPO 的 entropy bonus）成为主流探索手段

### 3.4 表格方法的极限

- 表格 Q 需要访问所有 (s,a) 组合——高维连续空间不可行
- 泛化缺失——未见过的状态无法估计
- 解决方案——**函数逼近**：Q_θ(s,a) ≈ Q*(s,a)——用神经网络拟合——由此进入深度 RL

## 四、深度强化学习：DQN 及其改进

### 4.1 DQN：经验回放与目标网络

2015 年 Nature 版 DQN——让 RL 在 Atari 上超越人类水平——两个关键技术：

**经验回放（Experience Replay）**：
- 把 (s, a, r, s') 存入回放缓冲区 D
- 训练时均匀采样 mini-batch——打破样本间的时间相关性——提高数据效率
- 允许"离线"学习——一条经验可被多次利用

**目标网络（Target Network）**：
- 维护一份"滞后"的参数副本 θ⁻——每隔 C 步同步
- TD 目标 y = r + γ max_a' Q_θ⁻(s', a') 用 θ⁻ 计算——减少"自举的追逐"导致的不稳定

**DQN 损失**：
```
L(θ) = E_{(s,a,r,s')~D} [ ( r + γ max_a' Q_θ⁻(s',a') - Q_θ(s,a) )² ]
```

### 4.2 Double DQN：消除高估偏差

标准 DQN 的 max 算子——同时负责"选择"与"评估"——会系统性高估 Q 值（最大化偏差）。

**Double DQN**——解耦"选择"与"评估"：

```
y = r + γ Q_θ⁻(s', argmax_a' Q_θ(s', a'))      （用在线网络选动作，目标网络估值）
```

- 大幅减小高估偏差——稳定训练——在许多游戏上效果优于 DQN

### 4.3 Dueling DQN：优势分解

把 Q 分解为"状态价值 + 优势"：

```
Q(s, a) = V(s) + A(s, a)
```

架构上——网络在输出层之前分成两个分支——最后合并。为防止"V 与 A 同时漂移导致不可识别"——用中心化约束：

```
Q(s, a) = V(s) + A(s, a) - mean_a' A(s, a')
```

- 价值分支能"无动作地"学习状态好坏——在动作影响小的场景加速学习
- 对价值近似更鲁棒

### 4.4 更多 DQN 改进（Rainbow 家族）

| 方法 | 核心思想 | 作用 |
|------|---------|------|
| Prioritized Replay | 按 TD 误差大小采样 | 聚焦"意外"样本——加速收敛 |
| NoisyNet | 在参数上加可学习噪声 | 状态依赖的探索 |
| Distributional RL (C51) | 学习回报的完整分布而非均值 | 保留风险信息——常带来免费增益 |
| n-step Returns | 用 n 步回报做目标 | 降低偏差、加速传播 |
| Rainbow | 上述全部组合 | Atari 上 SOTA 水平 |

### 4.5 策略梯度：REINFORCE

价值方法间接优化策略——策略梯度方法直接优化参数化策略 π_θ。

**策略梯度定理**（核心公式）：
```
∇J(θ) = E_π [ ∇_θ log π_θ(a|s) · Q_π(s, a) ]
```

**REINFORCE**——用回合回报 Gₜ 替代 Q：

```
θ ← θ + α Σₜ ∇_θ log π_θ(aₜ|sₜ) · Gₜ
```

- 无偏——但方差极大——加入**基线**（baseline）降低方差：

```
θ ← θ + α Σₜ ∇_θ log π_θ(aₜ|sₜ) · (Gₜ - b(sₜ))
```

- 任意与动作无关的 b(s) 不改变期望——但显著降低方差——常用基线：状态价值 V(s)

### 4.6 Actor-Critic：A2C/A3C

用"评论家"（Critic，价值网络）提供低方差的估计——"演员"（Actor，策略网络）更新策略：

```
Actor:  θ ← θ + α ∇_θ log π_θ(a|s) · δ         其中 δ = r + γV(s') - V(s)
Critic: w ← w + β ∇_w (r + γV_w(s') - V_w(s))²
```

- **A2C**（同步）与 **A3C**（异步并行 worker）——把 TD 误差当作优势估计——方差远小于 REINFORCE
- Actor-Critic 是后续 PPO、SAC、MAPPO 的"骨架"

## 五、PPO：近端策略优化

PPO（Proximal Policy Optimization）——OpenAI 2017 年提出——当前 RLHF 与在线 RL 的事实标准——在 TRPO 基础上简化——同时保持"更新不跑飞"的安全边界。

### 5.1 从 TRPO 到 PPO

**TRPO**——带 KL 约束的信任域优化：

```
maximize   E[ π_θ(a|s)/π_θₒₗₐ(a|s) · Â ]
subject to KL(π_θₒₗₐ ‖ π_θ) ≤ δ
```

- 数学上优美——但需共轭梯度法解约束——实现复杂

**PPO 的核心想法**——把硬约束变成软惩罚（或 clip）——用一阶优化即可。

### 5.2 Clip Loss（裁剪代理目标）

定义新旧策略比：

```
r_t(θ) = π_θ(aₜ|sₜ) / π_θₒₗₐ(aₜ|sₜ)
```

**PPO 目标**（核心公式）：
```
L^CLIP(θ) = E_t [ min( r_t(θ)·Âₜ, clip(r_t(θ), 1-ε, 1+ε)·Âₜ ) ]
```

- 当 r_t 超出 [1-ε, 1+ε]（通常 ε=0.2）——梯度被"夹住"——防止一步更新过大
- 当 Âₜ > 0（该动作好）——上限 1+ε——防止过度押注
- 当 Âₜ < 0（该动作差）——下限 1-ε——防止逃避惩罚
- 不引入额外约束优化——只需标准 Adam——是工程上最大的胜利

完整目标（含价值损失与熵奖励）：

```
L(θ) = L^CLIP(θ) - c₁·L^VF(θ) + c₂·S[π_θ](s)
```

- L^VF = (V_θ(s) - Rₜ)² 价值损失（也支持 clip 版本）
- S[π_θ] 熵奖励——鼓励探索——防止过早收敛到确定策略

### 5.3 GAE：广义优势估计

优势函数 Âₜ = Q - V——度量"比平均好多少"。GAE（Generalized Advantage Estimation）——用 λ 折中"偏差-方差"：

**核心公式**：
```
δₜ = rₜ + γV(sₜ₊₁) - V(sₜ)
Âₜ^GAE(γ, λ) = Σₗ₌₀^∞ (γλ)ˡ · δₜ₊ₗ
```

- λ = 0：退化为 TD 误差（高偏差、低方差）
- λ = 1：退化为蒙特卡洛（低偏差、高方差）
- 实践中 λ 取 0.95——γ 取 0.99（RLHF 中常取 0.99~1.0）

GAE 的递推实现：

```
伪代码:
  A = 0
  for t = T-1 down to 0:
      A = δₜ + γλ·A
      Âₜ = A
```

### 5.4 PPO 完整算法流程

```
1. 初始化策略 π_θ 与价值网络 V_φ
2. 循环:
   a. 用当前策略收集 T 步轨迹（多环境并行）
   b. 计算回报 Rₜ（GAE 或 λ-return）与优势 Âₜ
   c. 计算旧策略概率比（log-prob 存档，用于 r_t(θ)）
   d. for K 轮（通常 3~4 轮）:
      - 打乱数据，分 mini-batch（通常 64~256）
      - 对每个 mini-batch 用 Adam 更新 θ 与 φ
      - 应用 clip loss / value clip / entropy bonus
   e. 同步 θ_old ← θ（下一轮采集用）
3. 直到收敛
```

### 5.5 PPO 的实现细节（工程上决定成败）

| 细节 | 典型做法 | 作用 |
|------|---------|------|
| 优势归一化 | 对 batch 内 Âₜ 做 mean/std 归一化 | 稳定学习率 |
| 奖励归一化 | 滚动均值/方差归一化（RNN 环境） | 适应奖励尺度漂移 |
| value clip | V 目标也 clip 在 [1-ε,1+ε] 区间 | 防价值网络振荡 |
| 多个 epoch | 同一批数据用 3~4 次 | 提高样本效率 |
| GAE-λ 与 γ | λ=0.95, γ=0.99 | 偏差-方差权衡 |
| 熵系数 | 0~0.01（随训练衰减） | 控制探索 |
| 网络初始化 | 正交初始化 + 值输出小偏置 | 加速早期学习 |
| 长轨迹 | T=2048，16 环境并行 | 充分的数据覆盖 |
| KL 惩罚(可选) | PPO-KL 变体 | 更平滑的策略变化 |

### 5.6 PPO 的优势与局限

- **优点**：实现简单、超参数鲁棒、适用离散/连续动作、在线与批量皆可
- **局限**：样本效率仍低于 off-policy 方法（SAC）；对奖励信号敏感；熵坍塌风险；clip 是"软"约束——极端情况下仍可能大更新

## 六、SAC：最大熵强化学习

SAC（Soft Actor-Critic）——Haarnoja 2018——off-policy + 最大熵——连续控制 SOTA——也是很多 RLHF 变体的参考。

### 6.1 最大熵目标

标准 RL 最大化回报——SAC 最大化"回报 + 策略熵"：

```
J(π) = Σₜ E[ r(sₜ,aₜ) + α·H(π(·|sₜ)) ]
```

- 熵项鼓励"随机但合理"的策略——天然探索——鲁棒性强
- α 是温度系数——控制探索强度——可以自动调节（见 6.3）

### 6.2 软贝尔曼方程

定义软价值：

```
Q(s,a) = r(s,a) + γE[ V(s') ]
V(s) = E_{a~π}[ Q(s,a) ] - α·log π(a|s)   （软更新）
```

软 Q 的 TD 目标——用重参数化采样：

```
y = r + γ ( min_j Q_θ'ⱼ(s', ã') - α log π_φ(ã'|s') ),   ã' ~ π_φ
```

### 6.3 SAC 算法结构

- **两个 Q 网络**（clipped double-Q）——取 min——抑制高估
- **一个策略网络**——用重参数化（squashed Gaussian）：a = tanh(μ + σ·ε)
- **两个目标 Q 网络**（soft update：θ' ← τθ + (1-τ)θ'）
- **自动熵调节**——把 α 作为可学习参数：

```
L(α) = E[ -α·log π_φ(a|s) - α·H̄ ],   H̄ = -dim(A)（目标熵）
```

### 6.4 SAC vs TD3 vs PPO

| 方法 | 类型 | 探索 | 样本效率 | 稳定性 | 适用 |
|------|------|------|---------|--------|------|
| TD3 | off-policy, 确定性 | 加噪声 | 高 | 中 | 连续控制 |
| SAC | off-policy, 随机 | 熵 | 高 | 高 | 连续控制 |
| PPO | on-policy | 熵奖励 | 低 | 高 | 离散+连续、RLHF |

SAC 是"离线数据友好"的——加上 Replay 后常作为离线 RL（CQL 等）的基础。

## 七、多智能体强化学习 MARL

多智能体（MARL）——多个 agent 共存、协作或竞争——AGI 走向"多系统协作"的必经之路。

### 7.1 问题设定

- **随机博弈**（Stochastic Game）——MDP 的多智能体推广：由 (S, A¹..Aⁿ, P, R¹..Rⁿ, γ) 定义
- **合作**（fully cooperative，共同回报）、**竞争**（zero-sum）、**混合**（general-sum）
- **纳什均衡**——策略组合——任何单方偏离都无法改善——是价值最优的推广概念

### 7.2 核心挑战

1. **非平稳性**：每个 agent 的"环境"包含其他 agent——联合策略随时间变化——MDP 的平稳假设被破坏
2. **信用分配**：共享奖励下——难以判断"谁的贡献"
3. **可扩展性**：联合动作空间指数爆炸——|A|ⁿ
4. **对手建模**：需要推断/预测其他 agent 的策略

### 7.3 CTDE：集中训练、分散执行

**CTDE**（Centralized Training with Decentralized Execution）——MARL 的主流范式：

- 训练期：critic 能看到全部观测与动作（全局状态 s）
- 执行期：actor 只用自身观测 oᵢ 做决策
- 既缓解了非平稳性——又保持了执行的轻量可部署

```
训练期（集中）            执行期（分散）
┌──────────────────┐     ┌────────────┐
│ Q_总(s, a¹..aⁿ)   │     │ a¹ ← π¹(o¹) │
│ 价值网络看全局     │ ──→ │ a² ← π²(o²) │
│ 各 actor 只练自己  │     │ aⁿ ← πⁿ(oⁿ) │
└──────────────────┘     └────────────┘
```

### 7.4 值分解：VDN 与 QMIX

**VDN**——总价值等于个体价值之和：

```
Q_总 = Σᵢ Qᵢ(oᵢ, aᵢ)
```

**QMIX**——更灵活——用一个"混合网络"把个体 Q 组合成总 Q——并要求**单调性**（保证 argmax 一致性）：

**核心约束**：
```
∂Q_总 / ∂Qᵢ ≥ 0   （混合网络权重全为正）

Q_总 = Mixer( Q₁(o₁,a₁), ..., Qₙ(oₙ,aₙ); s )
```

- Mixer 是超网络（hypernetwork）——由全局状态 s 生成正权重
- **单调性**保证：如果每个 agent 取自己的 argmax——全局也是 argmax——执行期才能"分散贪心"
- 局限：只能表达单调的联合值函数——QTRAN、QPLEX 等扩展了表达能力

### 7.5 MAPPO：CTDE + PPO

**MAPPO**（2022）——把 PPO 放进 CTDE：

- actor：每个 agent 一个（或共享参数）策略——输入自身观测 oᵢ
- critic：**集中式价值函数**——输入全局状态 s（或拼接观测）
- 训练与 PPO 完全相同——clip、GAE、熵奖励——只是优势用集中 critic 计算
- 分享同一套超参数——就能在 SMAC、MAMuJoCo 等基准上达到 SOTA——说明"简单但正确"的框架力量

```
∇J(θᵢ) = E[ min(r_t(θᵢ)Âᵢ, clip(r_t(θᵢ))Âᵢ) ],   Âᵢ 来自全局 critic
```

**其他重要 MARL 方向**：反事实基线（COMA，信用分配）、自博弈（AlphaZero、OpenAI Five）、群体智能（SWARM）、人机协作（theory of mind）。

## 八、RL 与 LLM：RLHF、GRPO 与在线 RL

RL 在 LLM 时代"翻身"——后训练（post-training）成为 AGI 的关键环节。这里逐层拆解。

### 8.1 RLHF 的整体流程

**RLHF**（Reinforcement Learning from Human Feedback）三步走：

```
第 1 步: SFT —— 在人工演示上监督微调
第 2 步: RM  —— 人类对比标注 → 训练奖励模型（Bradley-Terry）
第 3 步: PPO —— 用奖励模型做"环境"，优化策略，配 KL 约束
```

**奖励模型训练**——Bradley-Terry 模型：

```
p(y_w ≻ y_l) = σ( r_φ(y_w) - r_φ(y_l) )
L_RM(φ) = -E[ log σ( r_φ(y_w) - r_φ(y_l) ) ]
```

### 8.2 RLHF 中的 PPO：语言生成的实现细节

语言生成被建模为"单轮 MDP"：状态 = 已生成的 token 序列；动作 = 下一个 token；episode = 一条完整回复。

**关键实现细节**：

- **KL 正则**——策略每步更新都必须贴近参考策略（SFT 模型）：

```
r_total = r_RM(y) - β·Σₜ KL[ π_θ(·|sₜ) ‖ π_ref(·|sₜ) ]
```

- **奖励只有末尾（sparse）**——token 级优势通过 GAE 从"最终奖励 + 逐 token KL 惩罚"回传
- **价值网络初始化**——常用 RM 的 value head 初始化——加速收敛
- **每个 prompt 只生成一次**（长度裁剪）——数据为 (prompt, response) 对
- **白盒 vs 黑盒**：OpenAI 使用"策略与奖励模型共用的基座 + KL 惩罚"；对不可访问的 API 模型——使用"rejection sampling + 蒸馏"（如 InstructGPT 的变体）

**Loss 配置（InstructGPT 风格）**：
```
L = L^CLIP - c₁·L^VF + c₂·S[π]   （价值损失 c₁=1，熵 c₂=0 通常）
γ = 1（无折扣，因为单轮对话）
λ = 0.95
```

### 8.3 GRPO：分组相对策略优化

**GRPO**（Group Relative Policy Optimization）——DeepSeekMath / DeepSeek-R1 提出——去掉了 PPO 中最贵的"价值网络"（critic）：

**核心思想**：对同一个 prompt 采样 G 个回答——用组内相对奖励计算优势——不需要额外学一个 critic：

```
对 prompt q，采样 {y₁,...,y_G} ~ π_θ_old
rᵢ = RM(yᵢ) （或可验证奖励）
Âᵢ = (rᵢ - mean(r)) / std(r)      ← 组内归一化的优势
L^GRPO(θ) = E[ min(r_t(θ)Âᵢ, clip(r_t(θ))Âᵢ) ] - β·KL[π_θ‖π_ref]
```

**为什么 GRPO 高效**：
- 去掉 critic——省一半显存与训练时间
- 组内相对化——自带奖励尺度归一化——对奖励分布漂移鲁棒
- 与"可验证奖励"（RLVR）天然契合——见 8.4

### 8.4 在线 RL 与可验证奖励（RLVR）

**RLVR**（RL with Verifiable Rewards）——DeepSeek-R1、OpenAI o1 的核心：

- 奖励来自**规则**而非奖励模型：数学答案精确匹配、代码通过测试（unit test）、LeetCode 判题
- 避免"奖励黑客"（reward hacking）——RM 可以被"讨好"——规则不行
- 与"长思维链"结合：模型被训练"多思考"——推理时 token 预算自动增加

```
GRPO + RLVR 的典型流程（R1 风格）:
1. 冷启动: 少量高质量 CoT 数据 SFT
2. 迭代 GRPO: 数学/代码/科学数据——规则奖励
3. 拒绝采样 + SFT 合并: 每轮把好样本再蒸馏回模型
4. 全场景 RL: 加入通用 RM（语言质量）混合训练
5. 推理时: 给思考预算（thinking budget）——越长越准
```

**其他相关方法**：
- **DPO/IPO/KTO**：直接偏好优化——无需显式 reward model——用隐式奖励闭式解
- **RLAIF**：用 AI 模型生成偏好标签替代人类
- **SFT→Rejection Sampling→DPO/RL**：Llama 3 的"post-training 流水线"
- **在线 RL**：策略自己生成数据再训练（self-play 式）——是通向"自我进化"的方向

### 8.5 RL 对 AGI 的意义：总结视角

```
LLM 预训练 ──→ 系统 1（快速、统计、联想）
RL/RLHF ──→ 系统 2（深思、规划、遵循目标）

缩放定律给了"知识"——RL 给"行为"
知识 × 行为 = 可交互、可推理、可对齐的智能体
```

- AlphaGo 证明：RL 可以在"规则确定"领域超越人类
- RLHF 证明：RL 可以把"人类偏好"编码进语言模型
- R1 证明：RL + 可验证奖励可以"激发"推理涌现——无需人工示范复杂推理
- 未来方向：世界模型 + 想象中 RL（Dreamer）、终身 RL、元 RL（学习如何学习）

## 九、总结

强化学习的完整地图：

```
MDP + 贝尔曼方程 ──→ 一切方法的理论根基
       │
       ├── 模型已知 ──→ 动态规划（策略迭代 / 价值迭代）
       │
       └── 模型未知 ──→ 时序差分 ──→ Q-Learning ──→ DQN ──→ Rainbow
                         │                 │
                         ├── 策略梯度 ─────┴──→ Actor-Critic
                         │                        │
                         │                        ├── PPO（clip + GAE）──→ RLHF
                         │                        └── SAC（最大熵）──→ 连续控制
                         │
                         └── 多智能体 ──→ CTDE ──→ QMIX / MAPPO
                                                    │
                                                    └── 大模型时代
                                                        ├── GRPO（无 critic）
                                                        └── RLVR（可验证奖励）
```

一句话总结：**贝尔曼方程给了 RL 目标——TD 给了它算法——神经网络给了它规模——而 LLM 给了它登上 AGI 舞台的机会**。下一代的 RL——很可能把"世界模型"装进想象空间——让智能体在"大脑中"试错亿万次——再在现实中行动一次。
