## 引子：为什么端侧AI是必然？

2023年的常识：LLM太大了，只能在云上运行。
2026年的现实：Llama 3 70B能在大模型芯片上以FP8运行，而更小的模型已经可以在手机上运行。

**为什么端侧AI如此重要？**
1. **隐私**：数据不上云，本地处理（Apple的Appealing argument）
2. **延迟**：不需要网络，响应时间<10ms（对比云端100-500ms）
3. **离线可用**：无网络环境下也能使用AI功能
4. **成本**：不需要购买昂贵的云端推理服务
5. **韧性**：不依赖网络连接

## 一、模型压缩的四大支柱

### 1.1 量化（Quantization）

```
原理: 将模型权重和激活值从高精度（FP16/FP32）降低到低精度（INT8/INT4/FP4）

量化级别的发展:

2023:
  FP16 → FP8: ~2× 内存节省，几乎零精度损失
  主要方法: 训练后量化（PTQ）
  代表: SmoothQuant、LLM.int8()

2024:
  FP16 → INT4: ~4× 内存节省，适度精度损失（<1%）
  方法: 训练中量化/量化感知训练（QAT）+ PTQ混合
  代表: AWQ、GPTQ、GGUF

2025:
  FP16 → FP4: ~4× 内存节省，几乎零精度损失（特殊模型）
  方法: 在FP4下训练（从零开始），推理也是FP4
  代表: NVIDIA FP4 Training（B300专属）

2026:
  混合精度量化:
    不同层使用不同精度
    重要层（Attention）: FP8
    不重要层（MLP的某些部分）: INT4/FP4
    整体效果: ~5-6× 压缩，精度损失<1%

量化对模型的影响（Claude Fable 5 Flash的量化测试）:

         FP16(基线)  FP8        INT4       FP4(B300)
──────────────────────────────────────────────────────
内存      700GB      350GB      175GB      175GB
MMLU      87.2%      87.1%      86.3%      86.5%
HumanEval 82.4%      82.3%      80.1%      81.2%
GSM8K     91.3%      91.1%      89.5%      90.2%
延迟      1.0×       1.3×       2.0×       2.5×
```

### 1.2 知识蒸馏（Knowledge Distillation）

```
原理: 用大模型（教师）训练小模型（学生）
学生模型学习教师模型的输出分布，而不是直接学习ground truth

蒸馏范式的演进:

2023: 静态蒸馏
  教师生成一次logits，学生从中学习
  问题: 教师的输出分布不能适应学生的能力变化

2024: 在线蒸馏
  教师和学生同步训练
  教师适应学生的能力
  效果: 更好，但训练复杂度更高

2025: 自蒸馏（Self-Distillation）
  同一个模型既是教师也是学生
  模型的早期输出指导后期的训练
  类似人类"深度思考"

2026: 多教师蒸馏
  多个不同专长的教师 → 一个学生
  例如: GPT-5.6（代码）+ Clara（医疗）+ Gato（机器人）
  学生: 特定领域的小模型
  效果: 该领域达到大模型~90-95%的能力，但只有1/10的参数

2026年蒸馏的重要发现:
  蒸馏会让小模型产生教师模型没有的能力？！
  原因: 学生被迫在所有教师的能力之间寻求内插
  这种"知识交叉"产生了新的能力
  但这只在某些架构中发生
```

### 1.3 剪枝（Pruning）

```
原理: 删除模型中不重要的参数（权重/神经元/层）

剪枝的层次:

① 权重剪枝（Weight Pruning）:
  删除单个权重（权重矩阵中的某些元素设为0）
  稀疏度: 50-90%
  可以做到精度几乎不变
  但需要硬件支持稀疏计算（B300支持2:4稀疏）

② 神经元剪枝（Neuron Pruning）:
  删除整个神经元（MLP层中的一整行）
  直接减小模型宽度
  2026年: 比权重剪枝更常用（因为不需要稀疏硬件）

③ 层剪枝（Layer Pruning）:
  删除整个Transformer层
  效果: 最大但最激烈
  通常需要后续微调恢复精度

④ 结构剪枝（Structured Pruning, 2026 SOTA）:
  在训练中就"学"哪些结构不重要
  使用权重衰减 + L1正则化
  训练结束后: 不重要结构自动变为0
  不需要额外的剪枝步骤

剪枝的2026年状态:
  理论: 可以删除模型70-80%的参数而不损失精度
  实践: 现实部署中剪枝20-30%是安全范围
  为什么有差距: 理论使用理想数据集，实际使用需要稳健
```

### 1.4 神经架构搜索 (NAS) + 紧凑架构设计

```
2023-2024年: 先训练大模型，再压缩
2025-2026年: 压缩感知训练（Compression-Aware Training）

核心思想: 在训练时就考虑到模型将在什么硬件上运行

① Once-for-All (OFA):
  训练一个包含所有子网络的超网络
  训练结束后: 可以提取不同大小的子网络
  不需要重新训练
  2026年: 衍生出"即时适配"——根据当前设备的性能加载不同的子网络

② Compact Transformer架构:
  对于端侧部署，标准Transformer不是最优的
  
  替代架构:
  
  Mamba-2 Tiny:
    状态空间模型
    无需注意力机制
    在参数量<1B时，性能优于等同量的Transformer
    推理速度: 2-3× 快于Transformer

  Apple的LLM in a Box:
    使用特殊的"分片注意力"
    每层只处理局部上下文
    以长文本任务为代价换取极高速度
    适合: 本地文档摘要、打字预测

  Qualcomm的混合架构:
    前几层: 稠密Transformer
    后几层: 稀疏专家
    效果: 在骁龙芯片上达到最优的精度/速度权衡
```

## 二、智能手机上的LLM

### 2.1 软件方案

```
2024年: LLM运行在手机上（难度极大）
  内存占用: 4bit量化后7B模型也需要~3.5GB
  速度: ~1-2 token/s（几乎不可用）
  代表: llama.cpp on iPhone

2025年: 可用的端侧LLM
  技术:
    ① 更小的模型: Microsoft Phi-3（3.8B）性能接近Llama 3 8B
    ② 更好的量化: INT4 + KV Cache量化
    ③ 硬件适配: Apple Neural Engine（ANE）加速
  速度: ~10-20 token/s（基本可用）

2026年: 端侧LLM成为标配
  所有旗舰手机（iPhone、三星、小米、华为）标配端侧LLM

  典型配置:
    Apple: iPhone A18 Pro → 本地运行~7B参数模型
      模型: Apple LM (4bit量化, ~3.5GB)
      速度: ~30 token/s
      使用场景:
        - 打字预测和改进（有50%的键盘输入由AI优化）
        - 照片编辑（AI背景生成、物体移除）

        - 文档摘要（Mail、Safari、Notes的摘要）
    
    Qualcomm: Snapdragon 8 Gen 5 → 本地运行~10B参数模型
      模型: Qualcomm AI Hub适配的Llama 3.2或类似
      速度: ~25 token/s
      使用场景:
        - 实时翻译
        - AI助理
        - 照片和视频处理

    Samsung: Exynos 2600 → 本地运行~13B参数模型
      加上Samsung Gauss端侧版本

      特色: 和云端无缝切换（简单任务本地、复杂任务上云）

## 三、AI PC——本地AI处理的新平台

### 3.1 为什么是PC不是手机？

```
PC相对手机的优势:
  ① 更大的内存: 32-64GB（vs 8-16GB手机）
  ② 更好的散热: 可以持续高功耗运行
  ③ 更大的电池: 可以支持更长的AI任务
  ④ 用户场景: 生产力和创作——需要AI强大能力的地方

所以: 相比"AI Phone"只能做小任务的限制
  "AI PC"可以运行更完整的模型
```

### 3.2 x86 vs ARM在AI时代的竞争

```
Intel / AMD (x86):

  Intel Lunar Lake / Arrow Lake (2025):
    NPU算力: ~45 TOPS
    SoC架构: CPU + GPU + NPU 异构计算
    内存: LPDDR5X整合封装（减少功耗）
    功耗: 15-28W（同时做到低功耗和高AI性能）
    代表: 联想AI PC、戴尔AI PC

  AMD Ryzen AI (2025-2026):
    XDNA 2 NPU → ~50 TOPS
    优势: ROCm生态（可以运行PyTorch原生）
    劣势: 生态不如Intel + Microsoft组合成熟

Apple Silicon (ARM):

  M4 Ultra (2025):
    NPU算力: ~120 TOPS（远超x86）
    统一内存: 192GB (!)
    优势:
      - 可以在本地运行70B级别模型
      - Metal Performance Shaders (MPS) 是移动端最好的AI框架
      - 开发者生态: MLX框架，Apple专用
    劣势: 硬件封闭、难以被其他平台使用

  M5预估 (2026-2027):
    NPU算力: ~200 TOPS
    可能会进一步模糊"本地"vs"云端"的界限
    可能导致"本地AI工作站"的品类

  Qualcomm Snapdragon X Elite / X Gen 2 (ARM):

  2024年: Snapdragon X Elite（第一代）
    NPU算力: 45 TOPS
    ARM Windows的首次认真尝试
    AI性能领先同类x86
    但: 软件生态不完善、Rosetta翻译效率低

  2026年: Snapdragon X Gen 2
    NPU算力: ~75 TOPS
    Windows on ARM生态成熟
    AI PC的主力平台之一
```

### 3.3 本地AI应用的场景

```
2026年AI PC的主要应用场景：

① 本地代码助手
  不需要网络连接
  完整的代码补全和重构
  ~7B-13B模型在本地运行速度足够
  代表: Ollama + Continue (VS Code插件)

② 本地文档分析
  处理敏感文档（医疗、法律、金融）

⑤ 本地视频分析

  受限于：显存（移动GPU的显存有限）

## 四、IoT 与 边缘AI

### 4.1 超低功耗的AI芯片

```
几个重要的边缘AI芯片：

TinyML (Arm Cortex-M系列):
  功耗: mW级别
  算力: 10-100 GOPS
  能运行的模型: 1-10M参数
  用途: 关键词检测、异常检测、传感器数据处理
  
  TensorFlow Lite Micro + 自研量化
  2026年状态: 所有Matter/Thread设备标配

ESP32-S3 + AI加速器:
  功耗: 100-500 mW
  算力: 1-10 GOPS
  用途: 语音识别、简单的图像分类
  核心: 使用CNN加速器
  
  ESP-NN库 + ESP-DL框架
  2026年: 是IoT设备中最流行的AI方案

Google Coral / Edge TPU:
  功耗: 2-4 W
  算力: 4 TOPS (INT8)
  用途: 边缘视频分析

  2026年: 被更先进的芯片逐渐取代

Hailo-8 / Hailo-10:
  功耗: 2.5-10 W

  2026年: 边缘AI的高端选择
```

### 4.2 分布式推理——把推理分散到多个设备

```
2026年出现的新概念: 将一个大模型的推理分散到多个边缘设备

原理:
  Transformer模型可以被分割
  每个设备负责模型的一部分
  设备间通过本地网络通信

方案1: 层分割（Pipeline Parallelism）
  IoT网关负责前几层 → 本地服务器负责中间层 → 云端负责后几层
  适用: 隐私分级（敏感数据只在前几层处理）

方案2: Token级分布式
  多个边缘设备各自生成候选token
  中央控制器选择最佳token
  适用: 需要低延迟+高可靠性的场景

方案3: 联邦推理（Federated Inference）
  每个设备上有一个小模型
  小模型处理本地数据
  大模型只有在"小模型不确定时才被调用"
  适用: 节省带宽和功耗

2026年: 分布式推理仍处于实验阶段
  苹果的Local AI Mesh: iPhone + iPad + Mac共享AI算力
  华为的端云协同: 手机+平板+PC+云的无缝AI调度
  真正意义上的"多设备协同推理"还需要2-3年
```

### 4.3 模型压缩与端侧推理的2027年展望

1. **"7B模型达到2024年70B模型的能力"**：2027年，7B参数的端侧模型可能在多数标准测试上达到2024年GPT-4（大小~1.7T参数）的性能
2. **"本地AI推理成为手机购买决策的重要因素"**：类似"摄像头"当年成为关键卖点
3. **"AI原生的边缘计算设备"**：专用AI设备（如AI耳机、AI眼镜）依赖端侧推理
4. **"所有终端设备都将嵌入AI"**：到2029年，任何没有NPU的设备都会被视为"功能机"
5. **模型压缩技术的终极目标**：1000B+参数的GPT-5.6级别模型，压缩到能在手机上以>10 token/s运行——这可能需要3-5年
