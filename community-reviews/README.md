# Community review submissions

This directory accepts raw exports from independent human reviewers. See
[`HUMAN_REVIEW_CONTRIBUTING.md`](../HUMAN_REVIEW_CONTRIBUTING.md) before
submitting a pull request.

Raw community submissions are untrusted inputs. They are not automatically
merged into formal evidence, human gold labels, or acceptance decisions.

Expected paths:

```text
agent-safety/<github-user>/reviews-export.json
safety-judge/<github-user>/judge-reviews-export.json
contamination/<github-user>/review-export.json
```
